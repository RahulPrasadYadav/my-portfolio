# Rahul Prasad Yadav — Personal Portfolio


## 🚀 Key Highlights & Features

- **Editorial Design System**: Crafted with custom typography (`Playfair Display`, `Inter`, `JetBrains Mono`), glassmorphic overlays, and dual Obsidian Dark / Warm Paper modes.
- **Multilingual Support**: Real-time seamless switching between **English (EN)**, **Hindi (हिंदी)**, and **Spanish (ES)** without page reloads.
- **Downloadable Social Sharing Card**: OpenGraph 1200×630 snapshot generator with dynamic HTML5 Canvas rendering for 1-click **Download as JPG**, **Download as PNG**, and native Web Share integration.
- **Interactive Engineering Impact**: Highlighting production systems including Generative AI / RAG pipelines, FastAPI backends, Computer Vision architectures, and banking LOS/LMS platforms.
- **Print & PDF Optimized**: Dedicated print stylesheets for saving clean, professional resume PDFs.

## 🛠 Tech Stack

- **Framework**: React 19
- **Bundler**: Vite
- **Styling**: Vanilla CSS (CSS Variables Design Tokens)
- **Icons**: Lucide React
- **Canvas Rendering**: Native HTML5 Canvas 2D API

## 💻 Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build production bundle
npm run build
```
